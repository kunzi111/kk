# Kunzi 个人网站

五个独立页面，导航打开对应界面，不是长页面锚点。纯静态，无构建步骤。

- `index.html`：首页。词标 `Kunzi.` 里嵌着一段循环影像，下面是索引带。
- `work.html`：作品入口（形态实验 / AI 伙伴）。
- `orbit.html`：粒子形态实验，可切换形态、暂停，桌面端可用指针改变倾角。
- `about.html`：简短个人介绍与一个巨型字母面板。
- `agent.html`：Agent 对话界面，当前仅本地预设回复。
- `app.js`：共享脚本，含粒子引擎与对话行为；样式内联在各页。

## 设计约定

- 单一深色主题：`--bg:#050505` / `--fg:#fafafa` / 强调色 `#99b9ff` 只用在句点、索引编号和焦点环三处。
- 字体：`Instrument Serif`（拉丁大标题）+ `Inter Tight`（UI 与中文）。
- 每页顶部有一段「令牌块」注释：五份 `:root` 变量需同步修改。
- 动效全部包在 `prefers-reduced-motion` 门内；首屏元素靠 `animation-fill-mode: forwards` 保证脚本失败也不空页。
- 首页词标用 Canvas 合成：视频铺满 → `destination-in` 用字形裁出可见区 → `source-atop` 给句点上色。下面压着一层实心文字作兜底。

## 预览

直接用浏览器打开 `index.html`，或在此目录运行：

```bash
python -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。本机预览，尚未发布到互联网。

## 检查

```bash
node ../qa/check-v3.cjs
```

需要本地服务已在 4173 端口运行。脚本会跑五页 × 三档视口的溢出与导航检查、词标画布、粒子封面、形态切换与暂停、对话交互与文本转义、reduced motion，并把截图写进 `qa/v3-*.png`。

> 注意：无头 Chrome 不解码远程 MP4，所以首页词标里的视频是否真的在播需要人工在浏览器里确认；画布本身有无视频都有渐变兜底。

## 后续接入 Agent

将 `app.js` 的 `demoAgent.reply` 替换为自己的后端 API 调用即可。目前没有模型、知识库、工具执行或长期记忆；消息不会上传，离开页面后清空。

模型密钥只放后端。接入私人资料和执行工具前，再设计访问权限。正式上线前替换个人介绍并加入真实作品与联系方式——现在全站还没有邮箱或社交链接。

## 需要你替换的部分

- 首页词标里的影像目前来自公开的示例媒体架，换成你自己的素材后质感会更私人。
- 作品页只有两件占位项目，补上真实作品与年份。
- 关于页的文案保持「不透露身份」的写法，如果你想写清楚，改 `about.html` 的 `.copy` 部分。
